Project Overview

This simple website demonstrates how to use Git and GitHub effectively while following a typical development workflow. The project includes:

  • Creating new branches
  • Making independent changes
  • Performing merges
  • Resolving merge conflicts

Technologies Used

The development is intentionally simple and lightweight so the focus remains on Git workflow.

  • HTML5 for page structure
  • CSS3 for styling
  • Git for version control
  • GitHub for hosting and collaboration

Learning Outcomes

By completing this assignment, I gained hands-on experience with Git commands, repository management, conflict resolution, and static website creation.
